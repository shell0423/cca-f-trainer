# CCA-F 合格トレーナー

**Claude Certified Architect – Foundations (CCA-F)** を、**日本語の教材**と**テスト**で
3ヶ月で合格レベルに到達するための学習サイトです。英語が苦手でも進められるよう、
解説はすべて日本語。各レッスンに「試験で出る英単語」を載せ、英語の本番に備えます。

## 使い方（URLで開く）

このサイトはローカルのHTTPサーバで開くのが推奨です（進捗の保存が安定します）。

```bash
# このフォルダで実行
python3 -m http.server 8000
```

ブラウザで次のURLを開いてください：

**http://localhost:8000**

> `index.html` をダブルクリックして直接開くこと（`file://`）もできますが、
> ブラウザによっては進捗保存が不安定になります。上記のURL方式を推奨します。

サーバを止めるには、ターミナルで `Ctrl + C` を押します。

## 学習の流れ

1. **教材を読む**（各ドメインのレッスン）
2. その場で **小テスト**（即時に正解・解説）
3. ドメインがひと通り終わったら **ドメイン試験**
4. 仕上げに **本番想定の模試（60問・120分）** と **ランダム模試**
5. 間違えた問題は自動で **「復習」** に溜まる → 空にするのが合格の近道

12週間の学習プランは、サイト上部の「**12週プラン**」から確認できます。

## 試験の概要（参考）

| 項目 | 内容 |
|---|---|
| 形式 | シナリオベースの多肢選択 |
| 問題数 / 時間 | 60問 / 120分 |
| 合格 | スケールドスコア 720 / 1000（約70%正答が目安） |
| 言語 | 英語 |
| ドメイン | D1 エージェント設計27% / D2 ツール・MCP18% / D3 Claude Code20% / D4 プロンプト・構造化出力20% / D5 本番運用・評価・コスト・安全性15% |

※本サイトはAnthropic非公式の学習補助ツールです。最新の正式な試験情報は
公式（Anthropic Academy / Skilljar、Claude Partner Network）をご確認ください。

## 構成（開発者向け）

```
index.html             サイト本体（SPA）
css/style.css          スタイル
js/registry.js         データ登録先（最初に読み込む）
js/markdown.js         教材本文のMarkdownレンダラ
js/storage.js          進捗・成績の保存（localStorage）
js/app.js              ルーター＋テストエンジン
js/data/curriculum.js  ドメイン情報・12週プラン・設定
js/data/d1..d5.js      各ドメインの教材＋問題
js/data/mock-1,2.js    本番想定の模試（各60問）
tools/validate.js      データ検証（node tools/validate.js）
```

データの妥当性チェック：

```bash
node tools/validate.js
```
